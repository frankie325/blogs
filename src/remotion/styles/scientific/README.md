# Field Notes · 科研观察手记

一套独立的科研科普动画风格：把画面设计成正在展开的研究手记，结合实验记录的条理、科学插图的精确感和杂志版面的留白。适合讲解模型结构、实验现象、空间关系和推理过程。

## 视觉语言

- **画布**：暖纸色底与极淡方格，像记录研究过程的工作台；图形区使用更浅的纸白色，避免大面积深色面板。
- **配色**：深墨绿 `#172d2c` 表示主要内容；孔雀绿 `#076f64` 表示正在观察的对象；朱红 `#c44b30` 表示结果或需要注意的关系；赭黄 `#bd8b31` 可用于对照。每个镜头明确颜色的具体含义，并搭配形状、线型或文字。
- **排版**：标题采用宋体风格，正文使用清晰无衬线，编号和变量使用等宽字体。中英文混排以标签为辅助，不为装饰堆砌术语。字体使用系统字体栈，不同系统的字形和换行可能不同。
- **构图**：偏好左侧提出问题、右侧展开图解；长横线、图号和小型注释建立“研究记录”感。其他镜头可改成全屏图解、前后对照或逐层拆解，不必固定左右分栏。
- **图形**：清楚的轮廓、局部放大、细引线和直接标注优先。图像不是纯装饰：位置、连接线和面积应反映要解释的关系。

## 动画语法

1. **观察**：先呈现完整背景，让观众知道正在看什么。
2. **聚焦**：选中一个元素，通过描边、局部放大或引线说明它的位置。
3. **解释**：逐步显示因果关系、公式或结果，留出阅读时间。

动效应由帧驱动，便于拖动时间轴和稳定渲染；避免无意义的漂浮或闪烁。所有示意数据、单位、坐标和非定量图形须明确标注。默认以 1280 × 720、30 fps 设计，内容距边缘至少 64 px；字号和留白需按博客实际显示宽度复查。

## 使用

在 Studio 选择 `ScientificStylePreview`，查看网格、局部放大、注释与逐步呈现的示例。示例图形仅用于展示视觉语言，并非实验数据。现有动画无需迁移。

```tsx
import {ScientificCanvas, ScientificLabel, scientificStyle, useScientificReveal} from './styles/scientific';

const Scene = () => {
  const opacity = useScientificReveal(0.5); // 0.5 秒开始，默认用 0.5 秒出现
  return <ScientificCanvas><div style={{opacity, color: scientificStyle.colors.focus}}><ScientificLabel>01 / OBSERVE</ScientificLabel>观察对象</div></ScientificCanvas>;
};
```

路径相对于 `src/remotion`；从其他目录引用时调整路径。制作完成后检查起始、变化和结果帧，以及缩小显示时的可读性、播放器控件遮挡和正文中的等价说明。
