# Deformable DETR 视觉素材与动画分镜

本文档服务于文章后续制图和动画制作。所有具体点位、颜色深浅、权重和框均为**示意数据**，不表示从训练权重中读取的实际结果。静态图使用可编辑 SVG，位于 `public/images/deformable-detr/`。

## 视觉约定

- 蓝色：图像特征、多尺度 Value 和 Encoder memory。
- 紫色：Query、位置表示和参考点。
- 橙色：采样偏移及最终采样位置。
- 绿色：注意力权重、加权聚合与输出。
- 薄灰色：辅助连接、网格和背景说明。
- 默认主线：单阶段、`WITH_BOX_REFINE=False`；框精修和 Two-Stage 必须单独标注为可选分支。

## 动画 A：一次多尺度可变形注意力

**目标**：回答“参考点在哪里、偏移和权重如何产生、最终如何读取并聚合特征”。默认使用 Decoder 的一个 Query，4 个头、4 层特征、每层 4 个点；先只展开一个头。

| 镜头 | 画面与动作 | 讲解重点 |
| --- | --- | --- |
| 1 | 显示一个 Query、一个二维参考点和四层特征图 | 单阶段初始参考点由 Query 的位置部分经线性层与 Sigmoid 得到；不是采样点本身。 |
| 2 | Query 分叉，分别经过两个线性层 | 一支产生 `M×L×K×2` 个偏移数值；另一支产生 `M×L×K` 个注意力 logits。 |
| 3 | 固定一个头，参考点映射到四层，各层出现四条偏移箭头 | 二维分支中，偏移按对应 `(W,H)` 归一化后与映射后的参考点相加；最终位置可以位于图外。 |
| 4 | 放大一个连续采样位置以及附近四个网格值 | 使用双线性插值获取特征；真实代码为 `grid_sample`、`align_corners=False`、图外零填充。 |
| 5 | 显示本头四层共 16 个 logits 共同进入 Softmax，然后逐点乘采样值 | 同一 Query、同一头在跨尺度的 16 个权重之和为 1；权重不跨头归一化。 |
| 6 | 四层加权结果相加，再展开四个头并拼接投影 | 每个头处理自己的 Value 通道子空间；四头合计 64 个采样位置。 |
| 7 | 回到整个 Decoder 层，显示 Query 和 Encoder memory 的来路 | Query 经自注意力后与位置表示一起用于预测；Value 来自 Encoder 的多尺度 memory。 |

数值特写可以使用 `H=32, W=40`、参考点 `(0.5, 0.5)`、偏移 `(4, -2)`，得到归一化采样位置 `(0.6, 0.4375)`。这些数字仅用于讲解坐标换算；制作时不要把它们标为真实推理结果。

## 动画 B：Encoder 参考点跨尺度映射

1. 从一个尺度中选择有效网格中心，标记其来源尺度和网格坐标。
2. 展示右侧、底部 padding，计算来源层有效宽高；将网格中心转换为相对有效区域的坐标。
3. 分别乘以四层各自的 `valid_ratios`，展示映射到各层完整特征图的归一化坐标。
4. 最后再叠加各尺度的采样偏移；参考点与采样位置用不同图形区分。

注意：padding 区域对应的 Value 会被置零；不要将采样点画成一定落在有效区域内。

## 动画 C：可选的逐层框精修

1. 明确打开 `WITH_BOX_REFINE=True`；显示单阶段初始二维参考点。
2. 第一层 Decoder 预测框，并将四维结果作为下一层参考框。
3. 后续层展示四维参考框的中心、宽高如何参与采样位置计算，以及当前层预测如何修正它。
4. 标注相邻层之间参考框的 `detach`；保留 Query 内容路径，避免暗示整个网络梯度被切断。

默认配置对照画面应显示：Query 内容逐层变化，各层可以输出不同预测框，但二维参考点本身不逐层更新。

## 发布前校验

- 图上每条箭头都能对应到本地模型的数据流；不要把普通 Decoder 自注意力画成可变形注意力。
- 参考点、采样偏移、采样位置、边界框回归偏移分别使用不同标识。
- 明确初始方向分布仅是偏移层的初始化，不代表训练后的固定采样模式。
- 二维坐标的顺序为 `(x,y)`，特征尺寸归一化顺序为 `(W,H)`。
- 框精修和 Two-Stage 只出现在标注过的可选分支中。
